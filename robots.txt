# POLICY: cite us, don't train on us.
#
# Rationale (full reasoning: agent-knowledge docs/strategy/web-visibility/02-crawler-policy):
# "AI: yes or no" is the wrong question. Retrieval and training are DIFFERENT crawlers
# with different user-agents, and for every vendor except Google they are separately
# controllable. So:
#
#   * RETRIEVAL / CITATION bots are ALLOWED. This blog exists to be read and cited.
#     A zero-click citation is a WIN here, not a loss — this site carries no ads, so
#     its value is credibility established, not impressions served. Blocking these
#     would remove the entire upside; eligibility is binary.
#
#   * BULK TRAINING crawlers are DISALLOWED. Measured cost of doing so is ~1% of search
#     traffic (Raptive, first-party data across 6,000+ sites), i.e. approximately nothing.
#     In exchange we keep a shred of leverage if content-licensing markets ever mature,
#     and the posture matches the own-the-stack ethic. Attribution flows back from
#     retrieval; it never flows back from a training corpus.
#
# Note this file is a PREFERENCE, not a control. Reputable crawlers honor it; some
# demonstrably do not (Cloudflare documented undeclared crawling against domains that
# disallowed all bots in both robots.txt and WAF rules, 2025-08). Treat it as a signed
# statement of our terms, and don't mistake it for enforcement.
